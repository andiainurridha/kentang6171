# Kentang6171 – UI Prototype

Prototype tampilan tiga halaman:
- `batching.html`
- `pengolahan-peta.html`
- `pengolahan-titik.html`

## Menjalankan
Buka salah satu file HTML di browser. Koneksi internet diperlukan untuk memuat Bootstrap 5 dan Bootstrap Icons dari CDN.

## Catatan
- Data pada tabel adalah data contoh/dummy untuk memperlihatkan desain, bukan data resmi.
- Search, filter, pagination, dan tombol aksi masih berupa elemen tampilan. Belum terhubung ke Google Spreadsheet.
- File CSS bersama berada di `css/style.css`.
- Setelah tampilan disetujui, tahap berikutnya adalah menambahkan JavaScript dan Google Apps Script sebagai API untuk membaca serta memperbarui Google Spreadsheet.
